# QuantLab — личная квант-лаборатория и тренажёр (российский рынок)

Cимулятор торговли с честной бухгалтерией,
маржой по российским конвенциям, финансированием и купонной математикой ОФЗ —
плюс лаборатории по стохастическим процессам и эконометрике поверх той же базы. Работает в терминале

## Установка

```bash
pip install -e ".[dev,quant]"
qlab init --capital 1000000        # счёт фиксированный, кнопки reset нет
```

## Быстрый старт (нужен доступ к iss.moex.com)

```bash
qlab add SBER                      # метаданные с MOEX ISS
qlab add SU26238RMFS4              # ОФЗ 26238: подтянет купонное расписание
qlab candles SBER --from 2024-01-01
qlab candles SU26238RMFS4 --from 2024-01-01

# ключевая ставка для плавающих займов: CSV `дата,процент`
echo "2024-07-26,18.0" > key_rate.csv
echo "2025-06-06,20.0" >> key_rate.csv
qlab rates load key_rate.csv

qlab buy SBER 100
qlab loan take 300000 --spread 0.05      # КС + 5%, ежедневная капитализация
qlab buy SU26238RMFS4 300
qlab tick                                 # прокрутить часы: проценты, купоны
qlab portfolio
qlab ledger
```

`--offline` у торговых команд использует последнюю дневную свечу вместо
живой котировки.

## Что уже реализовано (Phase 0)

| Модуль | Содержание |
|---|---|
| `core/ledger.py` | двойная запись; инвариант «батч суммируется в ноль» проверяется при постинге; позиции — материализация, леджер — истина |
| `core/execution.py` | маркет-ордера, fill-модель (спред + √-импакт при известном ADV), комиссии, шорты, частичные закрытия, флипы через ноль, средняя по WAC |
| `core/margin.py` | ставки риска (long/short), НМ/ММ по схеме НКЦ (`D_min = 1−√(1−D)`), машина состояний ok→restricted→margin_call, блокировка наращивания риска |
| `core/financing.py`, `core/accrual.py` | займы fixed / КС+спред, ACT/365, ежедневная капитализация по фиксингам; купоны, амортизации, погашения; линейный НКД |
| `moex/iss.py`, `moex/ingest.py` | ISS-клиент: метаданные, свечи с пагинацией, bondization, котировки; маршрутизация TQBR/TQOB/TQCB/TQTF/RFUD |
| `labs/ou.py` | первая лаборатория: OU через точную дискретизацию → AR(1)-MLE, симуляция без эйлеровского смещения, interpretation-объект |

## Архитектурные решения (и почему)

**SQLite + Decimal-as-TEXT.** Личный масштаб; деньги никогда не float.
Внимание: `SUM()` в SQLite коэрсит TEXT во float, поэтому балансы суммируются
в Python — не «оптимизировать» это обратно.

**Часы — атрибут счёта (`sim_time`).** Это то, что позже даст replay-режим
бесплатно: вторая учётная запись с `mode="replay"` и историческими свечами
вместо живых котировок, вся механика начислений уже не различает режимы.

**Цены облигаций.** ISS котирует в % от номинала; конверсия в рубли — на
границе (`cli._marks`), внутри движка всё в рублях за бумагу.

**Ставки риска** сейчас дефолтные по классу актива (`moex/ingest.DEFAULT_RISK`).
Реальные пер-инструментные — на сайте НКЦ; обновляй точечно по мере надобности.

## Дорожная карта следующих сессий

1. **Replay-режим**: `qlab replay create --from 2022-02-01` — второй счёт,
   котировки из исторических свечей, `tick` идёт по свечам. Механика готова,
   нужен только источник цен в `_marks` по `sim_time`.
2. **Лаборатории**: ARIMA/GARCH-обёртки (`statsmodels`/`arch`) с тем же
   interpretation-контрактом; ноутбук-примеры в `notebooks/`.
3. **Фьючерсы**: ГО вместо полной стоимости, вариационная маржа в клиринги
   (`vm`-лег уже зарезервирован в леджере).
4. **Принудительная ликвидация**: при `margin_call` — частичное закрытие от
   самого ликвидного, с дебрифом.
5. **НДФЛ-лег**: 13/15%, ЛДВ — отдельный отчёт по леджеру.
